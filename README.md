# CloudDesk IT Helpdesk

Full-stack IT Helpdesk and Ticket Management System built with **Python Flask**, **SQLAlchemy**, **Terraform**, **AWS**, and **GitHub Actions**.

## Local Setup

    python -m venv venv
    source venv/Scripts/activate  # Windows Git Bash (or source venv/bin/activate on Linux/macOS)
    pip install -r requirements.txt
    pytest -v
    python run.py

Open `http://127.0.0.1:5000` in your browser.
